AKUN MOCKUP / TEST WIRABUMI - SEMUA PERAN
(hanya untuk testing lokal, bukan data produksi)
========================================================
File ini: akun_mockup.txt (di root folder proyek, sejajar dengan
fitur_wirabumi.txt dan README.md).

CARA TERCEPAT DAPAT SEMUA AKUN INI: cukup jalankan start.bat lalu pilih
"Nyalakan Website WIRABUMI" - ini otomatis membuat schema database (kalau
belum ada) dan men-seed SEMUA 8 akun di bawah setiap kali dijalankan, jadi
tidak perlu perintah manual apapun. Kalau mau jalankan seed-nya saja secara
terpisah (server sudah menyala), perintahnya:

    npm run db:seed

Perintah ini menjalankan server/scripts/seed.js, yang membuat (atau
meng-update kalau sudah ada) SEMUA 8 akun di bawah, lengkap dengan data
pembukuan/pengeluaran yang realistis untuk tiap UMKM. Aman dijalankan
berulang kali - data lama akan dihapus dan diisi ulang segar (fresh).
Detail lengkap perintah setup dari nol ada di README.md.

CATATAN PENTING: menjalankan db:seed akan MENGGANTI transaksi akun
UMKM di bawah dengan data baru yang di-generate ulang (jumlah, tanggal,
nominal acak dalam rentang wajar) - jadi angka skor/omzet persisnya
bisa sedikit berbeda tiap kali di-seed ulang, tapi peran, email,
password, dan status konsen/bank tetap konsisten.
